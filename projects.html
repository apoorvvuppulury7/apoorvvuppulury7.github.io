VLSI · RTL

Asynchronous FIFO

Verilog Xilinx Vivado CDC

A CDC FIFO design that safely transfers data between two asynchronous clock domains. Gray-coded read/write pointers ensure only a single bit changes per increment, eliminating multi-bit metastability transitions when the pointers are synchronised across domains.

Architecture

  • Gray-code pointer arithmetic on both read and write sides to prevent multi-bit transitions
  • Dual flip-flop synchroniser chain on each pointer path to safely cross clock domains
  • FSM-based handshake protocol for reliable single-word data transfers
  • Full/empty flag generation derived from synchronised Gray-coded pointers

Verification

  • Functional simulation in Xilinx Vivado with corner-case timing stress tests
  • Waveform inspection of metastability windows under asymmetric clock ratios

Architecture · RTL

Pipelined RISC-V Processor

Verilog Xilinx Vivado Computer Architecture

A 5-stage pipelined RISC processor implementing a custom 32-bit ISA with R, I, and J-type instruction formats. The design covers the full processor datapath including hazard detection and data forwarding to keep the pipeline stall-free for most instruction sequences.

Pipeline Stages

  • IF — Instruction fetch with PC update logic and branch flush
  • ID — Register file read, immediate decode, and control signal generation
  • EX — ALU execution with full MUX-based forwarding from MEM and WB stages
  • MEM — Data memory read/write with load-use stall detection
  • WB — Register writeback with forwarding path outputs

Hazard Handling

  • Data forwarding from EX/MEM and MEM/WB pipeline registers to EX inputs
  • Load-use stall via pipeline register freeze and bubble insertion
  • Static branch prediction (predict-not-taken) with flush on misprediction

Verification

  • Waveform simulation in Xilinx Vivado against a hand-crafted assembly test program
  • Confirmed correct forwarding, stall, and flush behaviour across all hazard classes

Networks · ML

ML & QoS-Aware LEO Routing

Python DQN GNN LEO

An ML-driven routing framework for Low Earth Orbit (LEO) inter-satellite networks that combines Deep Q-Networks for adaptive path selection with Graph Neural Networks for topology-aware state representation. The system dynamically responds to link congestion and latency changes in a highly mobile satellite constellation.

Key Contributions

  • DQN agent trained on simulated LEO topology with QoS reward shaping (delay + satisfaction)
  • GNN-based state encoder captures multi-hop neighbourhood topology for each routing decision
  • 5–8% QoS satisfaction gain over benchmark shortest-path and load-balanced routing methods
  • 30–50 ms end-to-end delay reduction under high-traffic constellation scenarios

Implementation

  • Custom LEO network environment built in Python with configurable constellation parameters
  • PyTorch-based DQN with experience replay and target network stabilisation
  • GNN topology encoder using message-passing aggregation over inter-satellite link graph

6G · Comms Research

STAR-RIS Resource Allocation

MATLAB STAR-RIS 6G

A mathematical framework for joint resource allocation in Simultaneous Transmitting and Reflecting RIS (STAR-RIS) assisted networks operating under the MS (Mode-Switching) protocol. The work derives closed-form analytical bounds that quantify the trade-off between phase configuration error and element allocation between transmission and reflection.

Key Contributions

  • Formulated a joint optimisation problem for element splitting, beamforming, and power allocation
  • Derived analytical upper and lower bounds on achievable data rate under phase-error constraints
  • Demonstrated above-benchmark data-rate performance versus conventional RIS and baseline schemes
  • Quantified saturation behaviour of rate gain as the number of STAR-RIS elements increases

Tools & Methods

  • MATLAB for numerical evaluation of derived bounds and Monte Carlo channel averaging
  • Convex relaxation and successive convex approximation (SCA) for iterative optimisation

Wireless · Simulation

Smart Coverage Hole Remediation

MATLAB Stochastic Geometry Beamforming

A MATLAB-based stochastic network simulator that models base station and user distributions using Poisson Point Processes (PPP) to analytically characterise SINR distributions and identify coverage holes. A greedy STAR-RIS placement algorithm is then applied to remediate detected holes using passive beamforming.

Simulation Pipeline

  • PPP-based random network generation with configurable BS density and path-loss exponents
  • SINR mapping across the service area using stochastic geometry-derived expressions
  • Coverage-hole detection via threshold-based SINR classification on the spatial grid
  • Greedy STAR-RIS placement algorithm that maximises coverage gain per additional unit

Results

  • Coverage raised from ~55% to 100% using only two strategically placed STAR-RIS units
  • Validated that greedy placement achieves near-optimal coverage with minimal computational cost

Embedded · Vision

Embedded Collision Avoidance

Python OpenCV Jetson Nano

An embedded vision platform that performs real-time onboard obstacle detection and triggers autonomous evasive manoeuvres. The system runs entirely at the edge — no offboard compute — using an OpenCV-based image processing pipeline distributed across a Raspberry Pi and an NVIDIA Jetson Nano.

System Architecture

  • Raspberry Pi handles peripheral I/O, motor control signals, and low-level sensor interfacing
  • NVIDIA Jetson Nano runs the compute-intensive OpenCV detection pipeline using GPU acceleration
  • Inter-board communication over UART for low-latency evasion trigger signals
  • Frame-differencing and contour detection used to identify and localise obstacles in real time

Performance

  • Detection-to-evasion latency kept below real-time requirements for mobile platform speeds
  • Robust to varying ambient lighting through adaptive thresholding in the preprocessing stage
