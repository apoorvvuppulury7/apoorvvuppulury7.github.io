Asynchronous FIFO

Verilog Xilinx Vivado CDC

CDC FIFO with Gray-coded pointers and dual flip-flop synchronizers to eliminate metastability across asynchronous clock domains. FSM-based handshake for reliable single-word transfers.

Key Details

  • Gray-code pointer arithmetic to prevent multi-bit transitions during synchronization
  • Dual flip-flop synchronizer chain on both read and write pointer paths
  • FSM-based handshake protocol for safe single-word data transfers
  • Verified via timing simulation and functional waveform checks in Xilinx Vivado

Pipelined RISC-V Processor

Verilog Vivado Computer Architecture

5-stage pipelined RISC processor with full datapath, control logic, hazard detection, and data forwarding. Custom R/I/J-type ISA; verified via waveform simulation in Xilinx Vivado.

Key Details

  • IF → ID → EX → MEM → WB pipeline with full forwarding paths
  • Static branch prediction and flush logic for control hazards
  • Custom 32-bit R/I/J-type ISA with 20+ instructions
  • Waveform-verified against a hand-crafted test program
